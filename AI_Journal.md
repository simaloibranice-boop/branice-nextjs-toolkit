## Day 3: API Route Development

- **Prompt Used:**  
  "How do I create an API route in Next.js App Router?"

- **AI Response Summary:**  
  The AI explained that API routes must be inside `app/api/.../route.ts` and showed an example using `NextResponse`.

- **How AI Helped:**  
  Helped me fix a 404 error when accessing `/api/hello`.

- **Reflection:**  
  I understood the difference between Pages Router and App Router in Next.js.
